## 📝 Notes to myself
- Tech names have exact capitalization: **JavaScript, TypeScript, GitHub, npm, HTML, CSS**.
- The dev loop: **Edit → Save (Ctrl+S) → Refresh browser (F5)**.
- Ask my mentor (Claude) whenever I'm stuck. Getting stuck *is* the learning.
- **CSS comments can't be nested** — a comment ends at the FIRST `*/`. Never put `*/` inside comment text.
- **Reading linter errors** is a core pro skill — the red squiggles tell you exactly what's broken. Trust them.
